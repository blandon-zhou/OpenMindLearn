# OpenMindLearn 需求文档：生成交互与设置体验优化（2026-04-11）

## 1. 背景

当前产品在节点生成与设置相关体验上存在以下问题：

1. 右键“重新生成”时，输入框默认内容不是用户原始问题，导致重复编辑成本高。
2. 设置页面层级异常，出现“设置页面在详情页下方”的遮挡问题。
3. 生成过程不可中断，用户在误触或等待过久时无法主动停止。
4. Prompt 配置缺少“完整预览”，用户难以确认最终包装后的 prompt 是否符合预期。

## 2. 目标

1. 降低节点重新生成的重复输入成本。
2. 修复设置页面层级问题，保证设置弹窗始终可见且可操作。
3. 为所有生成链路提供“停止生成”能力，提升可控性。
4. 提供完整 prompt 预览能力，提升可理解性与可调试性。

## 3. 范围

本期范围包含：

1. 前端交互与状态管理改造（右键再生成、弹窗层级、停止按钮、prompt 预览）。
2. 生成请求取消链路（前端请求中止为主，后端按现有接口兼容）。
3. Prompt 预览所需的模板渲染结果展示。

本期不包含：

1. 流式生成（Streaming）重构。
2. Prompt 版本管理与历史对比系统。
3. 新增模型供应商或新的后端协议。

## 4. 功能需求

### 4.1 需求 A：右键节点“重新生成”默认预填原问题

#### 现状问题

“重新生成”入口打开后，默认内容并非节点原始 `question`，用户需要手工粘贴或重写问题。

#### 目标行为

1. 从节点右键菜单触发“重新生成”时，输入框默认值应为该节点的原始问题（`question`）。
2. 默认值可编辑，用户可修改后再提交。
3. 若该节点 `question` 为空，则回退为当前已有逻辑（例如空字符串或当前输入草稿），但不得报错。

#### 验收标准

1. 任意已有问题节点，打开“重新生成”时均自动带出原问题文本。
2. 用户可在预填文本基础上修改并成功生成。
3. 空问题节点不崩溃，仍可正常触发生成。

### 4.2 需求 B：修复“设置页面出现在详情页下方”问题

#### 现状问题

设置页面与详情页存在层级冲突，导致设置界面被遮挡或可见不可点。

#### 目标行为

1. 设置页面应作为全局最高优先级弹层（高于详情页及其遮罩）。
2. 设置页面打开后，详情页不可抢占焦点。
3. 关闭设置页面后，详情页状态按原逻辑恢复。

#### 验收标准

1. 在详情页已打开状态下打开设置页面，设置页面可完整显示并可操作。
2. 设置页面打开期间，点击详情页区域不会改变焦点或触发详情交互。
3. 桌面端和浏览器端表现一致，无层级闪烁或穿透点击。

### 4.3 需求 C：支持“停止生成”功能

#### 现状问题

生成任务启动后，用户只能等待完成或失败，无法主动停止。

#### 目标行为

1. 当存在进行中的生成任务时，界面提供清晰的“停止生成”操作入口（按钮或等价操作）。
2. 用户点击停止后，应立即中断当前生成请求（前端请求取消）。
3. 停止后界面状态应恢复为可继续操作，不保留“永久生成中”状态。
4. 停止行为应覆盖主要生成入口：首节点生成、节点扩展生成、节点重新生成。

#### 验收标准

1. 生成中可点击“停止生成”，请求被取消且不再继续写入该次结果。
2. 停止后可立即再次发起新的生成请求。
3. 停止后用户可收到明确反馈（如 toast：已停止生成）。

### 4.4 需求 D：支持完整 Prompt 预览

#### 现状问题

当前仅能编辑模板，无法直观看到“最终拼装后的完整 prompt”，调试成本高。

#### 目标行为

1. 在设置页新增“完整 Prompt 预览”能力。
2. 预览内容需展示最终渲染结果（包含 system prompt、模式模板、上下文包装结果）。
3. 用户可切换不同生成模式查看对应最终 prompt（直接展开 / 针对性提问 / 自定义上下文展开）。
4. 提供便捷复制能力，便于排查和对比。

#### 验收标准

1. 在设置中可看到当前配置下的完整 prompt 文本。
2. 切换模板配置后，预览内容可实时或手动刷新并反映最新结果。
3. 预览支持复制，不包含未解析占位符（除确无输入样例时的明确占位提示）。

## 5. 非功能要求

1. 交互响应：停止生成操作应在用户点击后立即反馈（UI 层面 < 300ms）。
2. 稳定性：新增功能不得破坏现有生成成功路径与设置保存路径。
3. 可维护性：复用现有 prompt 渲染逻辑，避免前后端出现两套不一致模板规则。

## 7. 里程碑建议

1. M1（P0）：完成 A+B（重新生成预填 + 设置层级修复）。
2. M2（P0）：完成 C（停止生成）并覆盖 3 条生成链路。
3. M3（P1）：完成 D（完整 prompt 预览 + 复制）并补齐交互细节。

## 8. 风险与注意事项

1. 停止生成若仅前端中止，需要明确后端超时与资源回收策略，避免后台仍长时间占用连接。
2. Prompt 预览应严格复用实际渲染函数，避免“预览可用、实际调用不一致”。
3. 弹层层级修复需统一 z-index 与 Portal 策略，避免后续新增弹窗再次冲突。
